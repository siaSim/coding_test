# 코드 리뷰 — [PCCE 기출문제] 2번 - 각도 합치기

**유형**: 산술 연산 / 입출력
**핵심 패턴**: 모듈러 연산으로 순환값 처리
**체감 난이도**: 매우 쉬움
**복습 필요도**: 하

## 1. 접근 방식
두 각도를 입력받아 더한 뒤 360으로 나눈 나머지를 출력.

## 2. 정확성 분석
정확합니다. 각도가 360을 넘어가는 경우를 모듈러 연산으로 자연스럽게 처리했습니다.

## 3. 복잡도 분석
O(1) / O(1).
