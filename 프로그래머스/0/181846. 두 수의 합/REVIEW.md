# 코드 리뷰 — 181846. 두 수의 합 (큰 수 문자열 덧셈)

**유형**: 문자열 처리 / 자릿수 연산 (carry)
**핵심 패턴**: 두 문자열을 자리별로 순회하며 carry를 넘기는 큰 수 덧셈
**체감 난이도**: 중간 (자릿수 단위 carry 처리가 핵심)
**복습 필요도**: 하

## 1. 접근 방식
두 숫자 문자열을 뒤집어 1의 자리부터 정렬한 뒤, 각 자릿수를 더하고 carry를 다음 자리로 넘기는 방식으로 큰 수 덧셈을 직접 구현했습니다.

## 2. 정확성 분석
정확합니다. 자릿수가 다른 경우 짧은 쪽을 0으로 채우는 처리(`x = int(a[i]) if i < len(a) else 0`), 마지막에 남은 carry를 추가로 붙이는 처리까지 모두 정확합니다.

## 3. 복잡도 분석
시간 O(max(n,m)), 공간 O(max(n,m)) — 최적입니다.
