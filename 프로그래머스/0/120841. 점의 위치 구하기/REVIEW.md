# 코드 리뷰 — 120841. 점의 위치 구하기

**유형**: 조건 분기
**핵심 패턴**: 사분면 판정 (중첩 조건문)
**체감 난이도**: 쉬움
**복습 필요도**: 하

## 1. 접근 방식
x, y 부호에 따라 중첩 if문으로 1~4사분면을 판정.

## 2. 정확성 분석
정확합니다. 표준 사분면 정의(Q1: x>0,y>0 / Q2: x<0,y>0 / Q3: x<0,y<0 / Q4: x>0,y<0)와 일치합니다. 문제 조건상 점이 축 위에 있지 않다고 보장되어 `>=0` 비교로도 안전합니다.

## 3. 복잡도 분석
O(1) / O(1).

## 4. 개선 제안
없음.

## 5. 코드 스타일
중첩 if문이 다소 깊지만 이 문제에선 이 방식이 가장 직관적입니다.
