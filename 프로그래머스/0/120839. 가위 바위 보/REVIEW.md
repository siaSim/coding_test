# 코드 리뷰 — 120839. 가위 바위 보

**유형**: 조건 매핑
**핵심 패턴**: 각 원소를 규칙에 따라 치환
**체감 난이도**: 쉬움
**복습 필요도**: 하

## 1. 접근 방식
가위(2)/바위(0)/보(5) 각각을 이기는 패로 치환.

## 2. 정확성 분석
정확합니다. 가위→바위(0), 바위→보(5), 보→가위(2) 승리 관계를 정확히 반영했습니다.

## 3. 복잡도 분석
O(n) / O(n).

## 4. 개선 제안
