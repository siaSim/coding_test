# 코드 리뷰 — [PCCE 기출문제] 3번 - 수 나누기

**유형**: 자릿수 분해 / 입출력
**핵심 패턴**: 두 자리씩 끊어 합산
**체감 난이도**: 쉬움
**복습 필요도**: 하

## 1. 접근 방식
`input()`으로 정수를 받아, 두 자리씩(`% 100`, `// 100`) 끊어가며 합산 후 `print()`로 출력.

## 2. 정확성 분석
정확합니다. 이 문제는 함수형(`solution`)이 아니라 표준입출력 형식이라는 점도 정확히 인지하고 작성했습니다. 자릿수가 항상 짝수 개라는 문제 제약 덕분에 `range(len(str(number)) // 2)`로 정확히 모든 자리가 커버됩니다.

## 3. 복잡도 분석
