# 코드 리뷰 — 120830. 양꼬치

**유형**: 산술 연산
**핵심 패턴**: 조건부 할인 계산
**체감 난이도**: 쉬움
**복습 필요도**: 하

## 1. 접근 방식
양꼬치 n개, 서비스로 받은 소주 개수(`n//10`)만큼 소주 값을 할인한 뒤 총액을 계산.

## 2. 정확성 분석
정확합니다. 10개당 소주 1병 무료 서비스를 `n//10`으로 정확히 반영했습니다.
