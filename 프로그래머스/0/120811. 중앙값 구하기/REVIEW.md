# 코드 리뷰 — 120811. 중앙값 구하기

**유형**: 정렬
**핵심 패턴**: 정렬 후 가운데 인덱스 접근
**체감 난이도**: 쉬움
**복습 필요도**: 하

## 1. 접근 방식
배열을 정렬한 뒤 가운데 인덱스(`len//2`)의 값을 반환.

## 2. 정확성 분석
정확합니다. 문제 제약상 배열 길이가 항상 홀수라는 전제가 있어 `len(array)//2`가 정확히 중앙값 인덱스입니다.

## 3. 복잡도 분석
시간 O(n log n)(정렬), 공간 O(n) 또는 O(log n)(정렬 구현에 따라).

## 4. 개선 제안
없음 — 이 크기(제약상 작은 배열)에서는 정렬 기반 풀이가 가장 간단하고 적절합니다. (참고: 배열이 매우 크고 자주 중앙값을 구해야 한다면 selection algorithm으로 O(n) 평균도 가능하지만 이 문제 규모에선 불필요합니다.)
