# 코드 리뷰 — 181905. 문자열 뒤집기

**유형**: 문자열 슬라이싱
**핵심 패턴**: 구간 분할 후 부분 반전
**체감 난이도**: 쉬움
**복습 필요도**: 하

## 1. 접근 방식
문자열을 `[0,s)`, `[s,e]`, `(e, 끝]` 세 구간으로 나눠 가운데 구간만 반전시켜 다시 합친다.

## 2. 정확성 분석
정확합니다. 슬라이싱 경계(`s`, `e+1`)를 정확히 처리했습니다.

## 3. 복잡도 분석
O(n) / O(n).

## 4. 개선 제안
없음.

## 5. 코드 스타일
구간을 변수로 나눠 이름 붙인 덕분에 가독성이 좋습니다.
