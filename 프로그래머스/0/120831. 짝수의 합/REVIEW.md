# 코드 리뷰 — 120831. 짝수의 합

**유형**: 배열 순회 / 집계
**핵심 패턴**: 조건에 맞는 값 누적 합
**체감 난이도**: 매우 쉬움
**복습 필요도**: 하

## 1. 접근 방식
1부터 n까지 순회하며 짝수만 합산.

## 2. 정확성 분석
정확합니다.

## 3. 복잡도 분석
O(n) / O(1).

## 4. 개선 제안
등차수열 합 공식을 쓰면 O(1)로도 가능합니다: 짝수 개수 `n//2`, 합은 `(n//2) * (n//2 + 1)`. 이 문제 규모에선 불필요하지만, 규모가 매우 커지는 변형 문제를 만나면 유용한 패턴입니다.

## 5. 코드 스타일
명확합니다.

## 6. 내가 막힌 지점 (추정)
없음.

## 7. 재풀이 기준
재풀이 불필요 (단, O(1) 공식 버전은 한 번 연습해볼 가치 있음).
