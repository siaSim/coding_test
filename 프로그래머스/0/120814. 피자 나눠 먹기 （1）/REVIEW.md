# 코드 리뷰 — 120814. 피자 나눠 먹기 (1)

**유형**: 산술 연산
**핵심 패턴**: 올림 나눗셈 (ceiling division)
**체감 난이도**: 쉬움
**복습 필요도**: 하

## 1. 접근 방식
`n // 7`을 기본으로 하고, 나머지가 있으면 1을 더해 올림 처리.

## 2. 정확성 분석
정확합니다. 올림 나눗셈을 조건문으로 직접 구현했습니다.

## 3. 복잡도 분석
O(1) / O(1).

## 4. 개선 제안
`-(-n // 7)` 또는 `math.ceil(n/7)`로 한 줄 처리도 가능하나, 지금 방식이 오히려 의도가 더 명확해서 그대로 둬도 좋습니다.

명확합니다.
