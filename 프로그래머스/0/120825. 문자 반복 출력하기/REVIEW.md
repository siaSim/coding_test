# 코드 리뷰 — 120825. 문자 반복 출력하기

**유형**: 문자열 처리
**핵심 패턴**: 문자별 반복 후 이어붙이기
**체감 난이도**: 매우 쉬움
**복습 필요도**: 하

## 1. 접근 방식
각 문자를 n번 반복해 이어붙인다.

## 2. 정확성 분석
정확합니다.

## 3. 복잡도 분석
O(n·k) (k=반복 횟수) / O(n·k) — 결과 문자열 크기 자체가 이 정도라 불가피합니다.

## 4. 개선 제안
주석 처리된 `''.join(i * n for i in my_string)`이 문자열 concat 반복(`+=`)보다 일반적으로 더 효율적입니다. 파이썬 문자열은 불변(immutable)이라 `+=`를 반복하면 매번 새 문자열을 만드는데, `join`은 이런 재할당을 줄여줍니다. 이 문제 크기에선 체감 차이가 없지만 습관으로 `join`을 쓰는 게 좋습니다.

## 5. 코드 스타일
대안 코드를 주석으로 남겨둔 점이 좋습니다.

없음.

## 7. 재풀이 기준
