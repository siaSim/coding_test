# 코드 리뷰 — 120892. 암호 해독

**유형**: 문자열 처리 / 인덱스 필터링
**핵심 패턴**: 1-indexed 배수 위치의 문자만 골라 이어붙이기
**체감 난이도**: 매우 쉬움
**복습 필요도**: 하

## 1. 접근 방식
`cipher`를 처음부터 끝까지 순회하면서, 인덱스를 1부터 시작한다고 볼 때(`i + 1`) `code`의 배수에 해당하는 위치의 문자만 `answer`에 이어붙였습니다.

## 2. 정확성 분석
정확합니다. `(i + 1) % code == 0` 조건은 "code의 배수 번째 글자"라는 문제 조건을 그대로 구현한 것이며, 공백도 일반 문자와 동일하게 처리되므로 제약사항("공백도 하나의 문자로 취급")도 만족합니다.

## 3. 복잡도 분석
시간 O(n), 공간 O(n/code) (n은 `cipher`의 길이). 최적입니다.

## 4. 개선 제안
슬라이싱을 쓰면 더 간결하게 표현할 수 있습니다.

```python
def solution(cipher, code):
    return cipher[code - 1::code]
```

`code - 1`부터 시작해 `code` 간격으로 건너뛰며 슬라이싱하면 반복문과 조건문 없이 한 줄로 동일한 결과를 얻습니다. 성능 차이는 미미하지만(둘 다 O(n)), 파이썬에서는 슬라이싱이 더 관용적인 표현입니다.

## 5. 코드 스타일
