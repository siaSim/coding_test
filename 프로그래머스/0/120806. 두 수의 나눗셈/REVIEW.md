# 코드 리뷰 — 120806. 두 수의 나눗셈

**유형**: 산술 연산
**핵심 패턴**: 정수 연산으로 실수 결과를 정수화
**체감 난이도**: 쉬움
**복습 필요도**: 하

## 1. 접근 방식
`(num1 * 1000) // num2`로 `floor(num1/num2 * 1000)`을 계산.

## 2. 정확성 분석
정확합니다. 부동소수점 연산(`num1/num2*1000` 후 `int()`) 대신 정수 곱셈을 먼저 해서 부동소수점 오차 위험을 피한 점이 좋습니다.

## 3. 복잡도 분석
O(1) / O(1).

## 4. 개선 제안
없음 — 부동소수점 오차를 피하는 정수 연산 순서가 오히려 더 안전한 선택입니다.
