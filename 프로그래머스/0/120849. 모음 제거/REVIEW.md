# 코드 리뷰 — 120849. 모음 제거

**유형**: 문자열 처리
**핵심 패턴**: 조건에 맞는 문자만 필터링
**체감 난이도**: 매우 쉬움
**복습 필요도**: 하

## 1. 접근 방식
문자열을 순회하며 모음이 아닌 문자만 이어붙인다.

## 2. 정확성 분석
정확합니다.

## 3. 복잡도 분석
O(n) / O(n).

## 4. 개선 제안
`''.join(ch for ch in my_string if ch not in 'aeiou')`로 줄일 수 있습니다 (선택 사항).

## 5. 코드 스타일
루프 변수명으로 `str`을 쓰고 있는데, 이는 파이썬 내장 타입 `str`을 가리는(shadow) 이름이라 좋지 않은 습관입니다. 이 코드에서는 문제가 되지 않지만, 같은 함수 안에서 `str(...)` 형변환이 필요해지는 순간 버그로 이어질 수 있습니다. `ch`나 `c` 같은 이름을 쓰는 걸 권장합니다.

## 6. 내가 막힌 지점 (추정)
없음.

## 7. 재풀이 기준
재풀이 불필요 (변수명만 습관적으로 고치면 됨).
