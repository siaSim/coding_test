# 코드 리뷰 — 120891. 369게임

**유형**: 문자열 처리 / 카운팅
**핵심 패턴**: 숫자를 문자열로 변환 후 특정 문자 집합에 속하는 개수 세기
**체감 난이도**: 매우 쉬움
**복습 필요도**: 하

## 1. 접근 방식
`order`를 문자열로 변환해 한 글자씩 순회하면서, 그 글자가 `'369'`에 포함되어 있으면(즉 3, 6, 9 중 하나면) 카운트를 1씩 늘려 반환합니다.

## 2. 정확성 분석
정확합니다. `order`는 제약사항상 1 이상의 정수(1 ≤ order ≤ 1,000,000)이므로 `str(order)` 변환에 부호나 소수점으로 인한 예외가 없고, `i in '369'`는 각 자릿수 문자가 '3', '6', '9' 중 하나인지를 정확히 판별합니다.

## 3. 복잡도 분석
시간 O(d), 공간 O(d) — d는 `order`의 자릿수(최대 7자리이므로 사실상 상수 시간). 최적입니다.

## 4. 개선 제안
자릿수가 적어 성능 차이는 없지만, 다음처럼 한 줄로도 표현할 수 있습니다.

```python
def solution(order):
    return sum(str(order).count(d) for d in '369')
```

또는 제너레이터 표현식으로:

```python
def solution(order):
    return sum(1 for i in str(order) if i in '369')
```

둘 다 가독성 측면의 대안일 뿐, 현재 코드도 충분히 명확합니다.

## 5. 코드 스타일
