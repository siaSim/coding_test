# 코드 리뷰 — 120821. 배열 뒤집기

**유형**: 배열 슬라이싱
**핵심 패턴**: 슬라이싱 역순 인덱싱(`[::-1]`)으로 배열을 뒤집기
**체감 난이도**: 매우 쉬움
**복습 필요도**: 하

## 1. 접근 방식
`num_list[::-1]` 슬라이싱으로 배열 순서를 뒤집은 새 배열을 반환합니다.

## 2. 정확성 분석
정확합니다. 파이썬 슬라이싱의 역순 스텝(`-1`)은 원소 개수나 값(0 포함, 중복 값 포함)에 관계없이 항상 전체 순서를 뒤집으므로, 주어진 제약조건(길이 1~1,000, 원소 0~1,000) 안에서 예외 없이 동작합니다.

## 3. 복잡도 분석
O(n) / O(n) — 결과 배열 크기가 입력과 같아 시간/공간 모두 불가피한 최소치입니다.

## 4. 개선 제안
이미 가장 간결하고 파이썬다운(idiomatic) 방식입니다. 추가로 줄일 부분은 없습니다.

## 5. 코드 스타일
명확합니다.

## 6. 내가 막힌 지점 (추정)
없음. 슬라이싱을 활용한 표준적인 배열 뒤집기 방식으로 막힘 없이 바로 최적 풀이에 도달한 것으로 보입니다.

## 7. 재풀이 기준
