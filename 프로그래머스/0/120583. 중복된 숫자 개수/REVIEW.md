# 코드 리뷰 — 120583. 중복된 숫자 개수

**유형**: 배열 순회 / 카운팅
**핵심 패턴**: 배열을 순회하며 조건에 맞는 원소 개수 세기
**체감 난이도**: 매우 쉬움
**복습 필요도**: 하

## 1. 접근 방식
`array`를 순회하면서 값이 `n`과 같은 원소 개수를 센다.

## 2. 정확성 분석
정확합니다. `array.count(n)`과 동일한 결과를 직접 구현한 형태입니다.

## 3. 복잡도 분석
시간 O(n), 공간 O(1).

## 4. 개선 제안
주석 처리된 `array.count(n)` 한 줄로 대체해도 됩니다 — 둘 다 O(n)이라 성능 차이는 없고 가독성만 다릅니다.

## 5. 코드 스타일
주석으로 대안 코드를 남겨둔 점이 좋습니다. 다만 실제 제출 코드와 주석 코드 중 하나는 정리해도 됩니다.

## 6. 내가 막힌 지점 (추정)
없음 — 매우 단순한 카운팅 문제라 막힐 지점이 없습니다.

## 7. 재풀이 기준
